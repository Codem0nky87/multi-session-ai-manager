# Development

## Generating the project

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
brew install xcodegen
cd app/MultiSessionAIManager
xcodegen generate
open MultiSessionAIManager.xcodeproj
```

`project.yml` is the source of truth for targets, signing, dependencies, **and
`Info.plist`** — the plist under `App/` is generated from `info.properties`.
Editing the generated `.pbxproj` or `App/Info.plist` directly means losing the
change on the next generate. That includes signing: ticking "Automatically
manage signing" in Xcode's UI is overwritten by the next run.

> **Adding a Swift file?** Re-run `xcodegen generate`. A new file that is not in
> the project is silently not compiled — and its tests are silently skipped —
> while `xcodebuild` still reports SUCCEEDED.

### Dependencies

| Package | Why |
|---|---|
| [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm) | Terminal emulation core (used headless) |
| [Citadel](https://github.com/orlandos-nl/Citadel) | SSH client, SFTP, exec |
| swift-nio-ssh | SSH transport |

`swift-nio-ssh` is pinned to the **fork** `Wellz26/swift-nio-ssh` at exactly
`0.3.4`, not Apple's upstream. Citadel depends on that fork because it
re-exports SPI symbols (`NIOSSHTransportProtection` and friends) that upstream
does not, and upstream has no `0.3.4` tag at all. Pointing this at
`apple/swift-nio-ssh` makes SPM substitute it and Citadel fails to compile.

## Tests

Over 550 unit tests, using
[Swift Testing](https://developer.apple.com/documentation/testing).

```sh
cd app/MultiSessionAIManager
xcodegen generate
xcodebuild -scheme MultiSessionAIManager \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' \
  -only-testing:MultiSessionAIManagerTests test
```

The unit suite is hermetic — it uses `FakeSSHTransport`, `FakeFileTransfer`, and
`FakeKeyInstaller`, and touches no network and no real host.

### Disposable-host session recovery diagnostic

> **Destructive opt-in only.** The following procedure stops a Herdr session,
> which terminates its pane processes; the reboot variant also interrupts SSH
> and every service on the machine. Run it only on a disposable macOS or Linux
> test host that you are authorized to restart, with console access available.
> Never run it on a workstation, shared server, production host, or a host that
> contains work you need. The ordinary unit suite must never run these commands.

Prerequisites:

- Herdr 0.8.2 or newer and SSH access are configured on the disposable host.
- AI Manager has a named tab `msam-restore-test`, and that tab is selected while
  the app remains in the foreground.
- The session has a recognizable multi-pane layout. If testing agent-native
  restore, use a supported agent, create a real conversation, and confirm its
  integration says `current` in **Host Setup → 4 · Session restore** (or with
  `herdr integration status`). Give Herdr a few seconds to persist recent
  layout/reference changes before stopping it.

First inventory the exact test session from a separate SSH shell:

```sh
herdr --version
herdr integration status
herdr session list
```

To test a Herdr-server death without rebooting the host, stop only the named
test session:

```sh
herdr session stop msam-restore-test
```

The selected foreground tab should notice PTY EOF, show reconnecting state, and
run `herdr --session msam-restore-test` again. It may recover on the immediate
attempt. Expect the saved layout and working directories, not the killed shell
processes. A supported agent conversation resumes only if Herdr saved a valid
native reference through a current integration and the agent accepts it. With
pane history left off, old screen contents are not replayed.

For the full host-loss path, repeat the setup and then, from the disposable
host's separate SSH shell, run:

```sh
sudo reboot
```

The app makes at most three automatic attempts: immediately, after 2 seconds,
and after 5 seconds. A normal reboot may outlast that budget; after SSH is back,
press **Retry** for a fresh three attempts. Confirm that no unselected tab tried
to connect and that a successful selected-tab attach restores the same named
layout. The file-transfer outbox watcher is reopened as part of a successful
attach.

Cleanup: close the named tab in AI Manager first so automatic recovery cannot
recreate it, then run these commands on the disposable host:

```sh
herdr session stop msam-restore-test
herdr session delete msam-restore-test
```

Finally remove the test host/key from AI Manager and decommission or reimage the
disposable host according to the test environment's normal cleanup policy.

### Live UI tests

`UITests/` drives the real app against a **pre-configured, reachable SSH host**.
They self-skip unless `MSAM_TEST_PW` / `TEST_RUNNER_MSAM_TEST_PW` is set, so the
default run stays hermetic.

```sh
MSAM_TEST_PW=… xcodebuild -scheme MultiSessionAIManager \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)' test
```

**Verifying terminal rendering.** Rendering fixes are verified by driving a real
TUI in the app and comparing what is on screen against `tmux capture-pane`
ground truth from the same session. Screenshots alone do not establish that the
emulator agrees with the host, and testing the shell after pressing Esc tests
the wrong thing.

## Running on a device

Build to an iPad from Xcode (iPadOS 17+). Signing is automatic against the team
in `project.yml`.

An in-place upgrade fails if the installed build was signed by a *different*
team — delete the app first when switching signing identity.

## TestFlight

```sh
cd app/MultiSessionAIManager
fastlane beta
```

The lane stamps a unique build number, mints the distribution certificate via
the App Store Connect API key, archives, and uploads to internal testing (no App
Review).

One-time setup:

```sh
brew install fastlane xcodegen

# App Store Connect API key, App Manager role, from Users and Access → Integrations.
# The .p8 downloads exactly once.
export ASC_KEY_ID=XXXXXXXXXX
export ASC_ISSUER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
export ASC_KEY_PATH="$HOME/.appstoreconnect/private_keys/AuthKey_XXXXXXXXXX.p8"
```

The `.p8` is gitignored (`**/*.p8`) and must never be committed. `fastlane`
needs `cert(api_key:)` for the distribution certificate; the auth flags belong
in `xcargs`, not `export_xcargs`.

Uploaded builds cannot be un-expired — expiring one in App Store Connect is
irreversible.

## CI

[`.github/workflows/ci.yml`](../.github/workflows/ci.yml) generates the project
and builds for the simulator with signing disabled, on push to `main` and on
every pull request.

## Conventions

- Swift 6, `@MainActor` by default. Framework completion handlers that can fire
  off-main must be `nonisolated`/`@Sendable` — a `@MainActor` callback invoked
  off-main traps at runtime, and `@preconcurrency import` does not save you.
- Formatting follows [`.swift-format`](../.swift-format).
- Comments explain *why*, especially where the obvious implementation is wrong.
  Much of this codebase's hard-won behaviour lives in those comments; the
  reasoning behind a guard is worth more than a restatement of it.
